# Terminal Migration

A reproducible playbook for rebuilding David's terminal and shell environment on
a fresh Mac.

From iTerm2 + Oh My Zsh + Vim to Ghostty + a fast zsh stack (antidote + Starship)
+ Neovim (LazyVim), keeping the existing tmux config. The end state is a single
`setup.sh` that stands the whole stack up from scratch, backed by per-tool research
and decision notes plus the captured dotfiles.

## Structure

Standard Cowork project layout. See `CLAUDE.md` (symlink to `AGENTS.md`) for
working conventions and `GOVERNANCE.md` for the research wiki rules.
